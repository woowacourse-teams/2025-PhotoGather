## 5. 무한 루프 방지

### ❌ isRetry 플래그 없이 (무한 루프)

```
API.request() → 401
    ↓
Auth.refreshToken() → 401
    ↓
API.request() → 401  ← 루프 시작
    ↓
Auth.refreshToken() → 401
    ↓
API.request() → 401
    ↓
... 무한 루프 ...
```

### ✅ isRetry 플래그 사용 (1회 재시도 후 중지)

```
API.request(url, options, isRetry=false) → 401
    ↓
Auth.refreshToken() → 새 토큰 받기
    ↓
API.request(url, options, isRetry=true) → 401
    ↓
if (isRetry) {
    Auth.clearTokens()
    Auth.redirectToLogin()
    중지 ← 더 이상 재시도 안 함
}
```

## 요약

- **정상 플로우**: 요청 → 200 OK → 완료
- **토큰 만료**: 요청 → 401 → 갱신 → 재시도 → 200 OK → 완료
- **동시 401들**: 여러 요청 → 모두 401 → 1회 갱신 → 모두 재시도 → 모두 200 OK
- **Refresh Token 만료**: 요청 → 401 → 갱신 → 401 → 토큰 삭제 → 로그인 페이지로 리다이렉트
- **무한 루프 방지**: isRetry 플래그가 재시도를 1회로 제한

**사용자는 토큰 만료를 절대 보지 못합니다**. 모든 것이 백그라운드에서 자동으로 처리됩니다.
